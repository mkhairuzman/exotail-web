# DESIGN.md — Exotail Landing Page

## 1. Project Overview

**Project:** Exotail Landing Page  
**Brand:** Exotail  
**Main Theme:** Modern Futuristic Aquatic  
**Visual Personality:** Friendly, clean, futuristic, aquatic, playful, and trustworthy  
**Primary Subject:** Axolotl / exotic aquatic pet brand

The landing page should follow the existing Exotail logo direction: rounded typography, strong purple identity, friendly mascot-like icon, and clean white space. The website must feel modern and futuristic, but should not look like a generic AI-generated startup website.

---

## 2. Design Goal

The landing page should communicate that Exotail is a modern brand for axolotl lovers and exotic aquatic pet owners.

The experience should feel:

- Modern
- Futuristic
- Aquatic
- Friendly
- Playful
- Trustworthy
- Clean and premium
- Real, not overly AI-generated

The page should combine **real axolotl/aquarium photography** with **custom lightweight mascot animation** to make the brand feel alive and original.

---

## 3. Core Design Direction

### Final Style Direction

**Modern Futuristic Aquatic with Custom Animated Axolotl Mascot**

The design should use a mix of:

- Dark futuristic aquatic hero section
- Clean white/lavender content sections
- Purple brand identity
- Aqua/mint glow accents
- Rounded UI components
- Real axolotl photos for authenticity
- Simple custom axolotl animation for brand personality

### Design Reference Feeling

Think of:

- A modern exotic pet brand
- A soft digital aquarium
- A friendly aquatic care platform
- A clean landing page with playful mascot details

Avoid making it look like:

- Generic AI SaaS website
- Overly glossy 3D website
- Neon gaming website
- Childish cartoon website
- Template-generated landing page

## 4. Brand Visual Identity

## 4.1 Logo Usage

Use the uploaded Exotail logo as the main brand reference.

1. **Horizontal wordmark**

- Do not distort, stretch, rotate, or recolor randomly.

## 7. Animation Direction

The landing page should include axolotl animation, but since there is no ready asset yet, the first version should use a custom lightweight vector-based animation.

## 7.1 Recommended Animation Approach

### Option A — SVG / CSS Animation

Best for MVP.

Create a simple custom axolotl mascot using SVG shapes:
- Rounded head
- Simple eyes
- Soft gills inspired by the Exotail logo splash
- Small tail
- Bubble elements

Animation behavior:
- Floating up and down
- Tail wiggle
- Gills breathing softly
- Eye blink
- Bubbles rising slowly

Benefits:
- Lightweight
- Easy to implement
- Responsive
- Not dependent on video
- Does not look like generic AI art

### Option B — Lottie Animation

Best for premium version.

Create a custom axolotl illustration and export as Lottie JSON.

Animation behavior:
- Axolotl swims slowly
- Bubbles rise
- Eyes blink
- Tail moves naturally
- Axolotl floats inside a digital aquarium shape

Benefits:
- Smooth
- Premium
- Great for mobile
- Brandable

### Option C — 3D Mascot

Not recommended for first version.

Reason:
- Higher risk of looking AI-generated
- Heavier website performance
- Needs more asset preparation

- Headline, subheadline, then CTA below the mascot

Mobile mascot note:
- iOS Safari does not get the transparent WebM video; it gets a clean static

## 9. Responsive Design

## Desktop

- Hero uses 2-column layout.
- Animation can be larger and more detailed.
- Cards use 3 or 4-column grid.
- Gallery can use masonry layout.

## Tablet

- Hero remains 2-column if enough space.
- Cards use 2-column grid.
- Gallery uses 2-column grid.

## Mobile

- Hero becomes single-column.
- Mascot animation comes first, text second.
- CTA buttons should be easy to tap.
- Cards stack vertically.
- Gallery can become horizontal scroll.
- Keep spacing generous.
- Avoid too much animation on mobile.

Recommended mobile spacing:
- Section padding: `56px 20px`
- Hero padding top: `80px`
- Card padding: `20px`
- Button height: minimum `44px`

### Motion Guidelines

Use motion for:
- Hero mascot floating
- Bubble movement

- Card hover
- Section entrance fade

- Heavy parallax

### Performance Notes

- Use Lottie only if file size is reasonable.

## 13. Example CSS Animation Direction

For MVP, the axolotl mascot can be built as an SVG component.

Animation behavior:

```css
.axolotl {
  animation: floatAxolotl 5s ease-in-out infinite;
}

.axolotl-tail {
  transform-origin: center;
  animation: tailWiggle 2.8s ease-in-out infinite;
}

.axolotl-gill {
  transform-origin: center;
  animation: gillBreath 3.2s ease-in-out infinite;
}

.bubble {
  animation: bubbleRise 6s linear infinite;
}

@keyframes floatAxolotl {
  0%, 100% {
    transform: translateY(0px);
  }
  50% {
    transform: translateY(-14px);
  }
}

@keyframes tailWiggle {
  0%, 100% {
    transform: rotate(0deg);
  }
  50% {
    transform: rotate(5deg);
  }
}

@keyframes gillBreath {
  0%, 100% {
    transform: scale(1);
    opacity: 0.9;
  }
  50% {
    transform: scale(1.06);
    opacity: 1;
  }
}

@keyframes bubbleRise {
  from {
    transform: translateY(20px);
    opacity: 0;
  }
  20% {
    opacity: 0.8;
  }
  to {
    transform: translateY(-120px);
    opacity: 0;
  }
}
```
